# Changelog

All notable changes to the Claude theme are documented here.

## 1.0.0

- Initial public release of the Claude-inspired Obsidian theme.
- Added Default and Warm light palettes with a coordinated dark palette.
- Added bundled Geist Sans, Lora, Literata, and Source Code Pro typography.
- Added Style Settings controls for light palette, status-bar auto-hide, and
  Obsidian Sync visibility.
- Refined window chrome, tabs, sidebars, explorer actions, metadata, code,
  tables, modals, prompts, and status-bar surfaces.
